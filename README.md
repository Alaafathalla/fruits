# Fruit Slash 3D

An interactive fruit-slicing browser game with a Three.js scene and a React interface.

[Live demo](https://fruits-woad.vercel.app/)

## Included interfaces

- Three.js fruit-slicing scene.
- Score, combo, timer and progress interface.
- Arcade and Zen mode controls.
- Fruit collection counters and recipe-style goals.

## Built with

Next.js, React, TypeScript and Three.js.

## Run locally

Install a Node.js version supported by the framework dependencies in `package.json`.

```bash
npm install
npm run dev
```

Open the local URL printed by the development server.

## Production build

```bash
npm run build
```
